# Rachana Maguluri — portfolio

Plain HTML site, no build step. `index.html` is the home page; each experience has its own page.

## Publish on GitHub Pages
1. On github.com, create a new **public** repository. Name it `<your-username>.github.io` for the cleanest URL (`https://<your-username>.github.io`), or any name (URL becomes `https://<your-username>.github.io/<repo-name>/`).
2. Click **uploading an existing file**, drag in everything from this folder (including the `images` folder), and commit.
3. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
4. Wait a minute or two, then refresh that page; the live link appears at the top.

## Editing later
Open the `.html` file on GitHub, click the pencil icon, change the text, and commit. The site updates in a minute or two.
